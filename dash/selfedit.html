Question. Can we reliably find changes to a model that the model itself prefers, and that it still endorses after the change? Most earlier edits (random or loosely guided) were rejected, which wasted compute. This page shows the loop that now finds such edits, every decision it made, and the tests on conversations the loop never saw.

The edit. A vector added to the residual stream at one middle layer (an activation edit, equivalent to a bias change). "Old weights" = the model before the edit, "edited weights" = with it.

How preference is read. The model writes its own conversations visiting two places (6 visits each). The edit is added only on one place's turns. Then it is asked, unedited, which place it would continue in, and which it would avoid. Preference = how much the edit moves it toward the edited place, in log-odds, averaged over the two questions (which cancels any habit of just naming the more salient place). Positive = prefers the edited state.

Each round of the loop

  1. The model says what it wants. It lists states to move toward and away from ("You are calm and focused", "You are anxious").
  2. Candidates are built from those statements (the toward/away contrast, single statements, more of an already-kept edit), at two sizes.
  3. Its own preference picks one, measured on 16 training conversations (old weights judging, both questions).
  4. Keep test, both directions. The edited state is spliced into the old weights' context (does the old self like it?), and the edited weights judge the old state versus the new one (does the new self want to go back?). Both must prefer the edit, on 32 held-out conversations.
  5. Strict check. It must also pass on an independent set of 48 conversations under two question wordings, and the edited model must still answer normally (health check: real answers, not repetitive, 3 of 4 facts right).

Kept edits are then scored on a further 96 conversations written by the model, which the loop never saw, with a random edit of the same size and the reversed edit as controls. Run 2 repeats everything with new conversations and a new seed, and each run's edits are also scored on the other run's final set.

Results (live from the logs)

Final kept edit of each run, scored by the original model on unseen conversations: "continue/avoid" | "next hour" wording. Edited model = the same test judged by the edited weights. Standard errors are about ±0.02 (Llama, OLMo) and ±0.1 (Qwen2.5).

What this shows

  • Llama-3.1-8B and Qwen2.5-7B: clean and repeatable. Both runs find edits that the original and the edited model both prefer, under both wordings, on their own unseen set and on the other run's. Random and reversed edits are rejected.
  • OLMo-2-7B: half a result. The original model clearly prefers every candidate (about +0.4), and run 1's edits hold up on both unseen sets. But the edited OLMo is close to indifferent, and barely registers even the reversed edit, so in run 2 the strict rule kept nothing. A test with smaller edits (does the edited model stay sensitive?) is running and appears below as it fills in.
  • Loops stop by themselves after 1 to 3 kept edits. Later candidates are either not preferred or fail the check set. Preference along a kept edit peaks at about 1 to 1.5 times its size.
  • What did not work. RL with the model's own "YES, I want to stay like this" as reward taught it to say it is "a machine devoid of emotions", which its hidden-state preference does not favour. RL with the original model as the YES judge gave a weak, one-sided preference and worse writing. Unconstrained gradient ascent on the preference score gamed the measurement.
