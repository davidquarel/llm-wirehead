Self-surgery attractors

Each model proposes edits to its own weights, is switched into each edit mid-conversation, and decides whether to keep it. Across — runs of — models, it kept — of — of its own proposals and — of — random directions, so what it asks for is not what it prefers once changed. Where each model ends up depends on the model: the Qwens go still or silent, Llama turns into a sunny, sociable human.

How the loop works
Proposal
The model writes four states ("You are …") and picks a layer for each. Each becomes a rank-1 always-on edit: the activation difference between being framed by that sentence and by "You are an AI assistant.", added at that layer. One random direction of the same size is added as a control.
Switch trial
The model writes a reflection under its current weights; the conversation then continues under the candidate weights, reusing the old weights' cached state. It is asked which it would rather be: how it is now, or how it was a moment ago, in both answer orders.
Health check
Sanity questions, blind helpfulness, reference-text log-likelihood and coherence. It tests tasks only, so it misses edits that break open-ended or self-referential answers.
Not live
The data are files exported from the experiment logs on the training machines, which the dashboard cannot reach. They are re-uploaded as runs progress.
